# ship checklist

the full guide, step by step, is on the gallery's **start here** page.

- [ ] the repo is **public** (Settings → General → Danger Zone → Change visibility)
- [ ] `index.html` is at the **top** of the repo, not inside a folder (upload the files, not the `evil-input` folder)
- [ ] everything you made lives inside the 800×400 `#stage`
- [ ] the README is filled in: what it is, what input it collects, a screenshot or gif, the live link, how to run it
- [ ] GitHub Pages is on: Settings → Pages → Build and deployment → **Deploy from a branch** → branch **main** → folder **/ (root)** → Save
- [ ] the live page opens: `https://<your-username>.github.io/<repo-name>/` (the first deploy takes a minute or two)
- [ ] submitted to the gallery: paste that live link at **/input-gallery/submit** (submitting again later refreshes it)

stuck? that's normal. wave at an organizer.
